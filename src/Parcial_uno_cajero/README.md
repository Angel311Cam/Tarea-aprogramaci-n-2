## Descripción

Este proyecto simula las operaciones básicas de un cajero automático para una sola cuenta bancaria.
El programa permite ingresar mediante PIN, consultar saldo, realizar depósitos, retiros normales y retiros con comisión,
además de mostrar un resumen de las operaciones realizadas.

## Ejecución

Para ejecutar el programa, abrir la clase `CajeroAutomatico.java` desde IntelliJ IDEA y ejecutar el método `main`.
