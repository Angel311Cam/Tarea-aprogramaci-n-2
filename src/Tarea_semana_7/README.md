# Sistema de Gestión de Envíos

## Descripción

Este proyecto consiste en un programa desarrollado en **Java** para gestionar diferentes tipos de envíos. 
El sistema permite trabajar con envíos nacionales e internacionales, aplicando conceptos de programación orientada a objetos.

El proyecto fue desarrollado como parte de las actividades de **Programación I**, con el objetivo de poner 
en práctica la creación de clases, atributos, métodos, herencia y organización de archivos dentro de un proyecto Java.

## Funcionalidades

El programa permite:

* Crear y gestionar envíos.
* Trabajar con envíos nacionales.
* Trabajar con envíos internacionales.
* Calcular información relacionada con cada envío.
* Utilizar clases y objetos.
* Aplicar herencia entre las diferentes clases.
* Organizar el código en archivos independientes.

## Estructura del proyecto

El proyecto contiene las siguientes clases principales:

```text
src/
└── main/
    ├── Main.java
    ├── Envio.java
    ├── EnvioNacional.java
    └── EnvioInternacional.java
```

### Clases

**Main.java**
Contiene el método principal del programa y permite ejecutar el sistema.

**Envio.java**
Es la clase base que contiene las características generales de un envío.

**EnvioNacional.java**
Representa los envíos realizados dentro del territorio nacional y hereda características de la clase `Envio`.

**EnvioInternacional.java**
Representa los envíos realizados hacia otros países y hereda características de la clase `Envio`.


## Objetivo académico

El objetivo principal de este proyecto es practicar los fundamentos de **Programación Orientada a Objetos en Java
especialmente el uso de clases, objetos, métodos, atributos y herencia.

**Cómo usar el programa**

1. Abrir el proyecto

Abrir el proyecto utilizando IntelliJ IDEA.

2. Verificar los archivos

Comprobar que dentro de la carpeta src/main se encuentren los siguientes archivos:

Main.java
Envio.java
EnvioNacional.java
EnvioInternacional.java
3. Ejecutar el programa

Abrir el archivo Main.java y localizar el método:

public static void main(String[] args)

Luego presionar el botón Run ▶ que aparece en IntelliJ IDEA.

4. Utilizar el sistema

Una vez ejecutado, el programa mostrará las opciones disponibles en la consola.

El usuario deberá seleccionar la opción correspondiente e ingresar los datos solicitados por el programa.

Dependiendo de la opción seleccionada, se podrá trabajar con:

Envíos generales.
Envíos nacionales.
Envíos internacionales.
Cálculos relacionados con los envíos.
5. Finalizar el programa

Para terminar la ejecución, utilizar la opción de salida que proporciona el programa.
